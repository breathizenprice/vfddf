## Common problems and how to diagnose them

Troubleshooting is faster when each symptom is tested separately. The checks below apply to common Epson printer workflows; model-specific controls may differ.

### Paper feeds incorrectly

Remove damaged paper, fan the stack, align the guides without squeezing, and check for torn pieces in the paper path. Follow the manual before opening covers.

### A downloaded file seems suspicious

Check the publisher and source. Do not run password-protected archives from unknown sites, disable security software, or grant remote access to strangers.

### Printer is not detected

Check that the device is powered on, that the USB cable is firmly connected, or that the printer and computer are on the expected network. Try a different port or cable when using USB. Restart the computer before reinstalling software.

### The printer shows offline

Check power, connection, default printer selection, and the queue. A printer can show offline even when its hardware is functional because the configured port or network changed.

### Wireless connection fails

For Wi-Fi-capable models, check the network name, password, router proximity, and network band support. The L3110 has no built-in Wi-Fi; use USB for that model.

### Print jobs stay in the queue

Open the printer queue, remove stuck jobs, and make sure Pause Printing and Use Printer Offline are not selected. Restart the Print Spooler service only if basic checks fail.

### Printer reports a service warning

Read the exact message. Some warnings indicate physical maintenance rather than a driver fault. Do not bypass maintenance counters without addressing the underlying service requirement.

### Printed colors look incorrect

Confirm the correct paper type and print settings, then run a nozzle check. Use the appropriate printhead maintenance only when the diagnostic pattern supports it.

### Scanner does not open

Verify that the scanner component is installed and that the device is recognized. Try the official Epson scanning application, then test with a simple single-page scan.

## Safety, compatibility, and maintenance considerations

A reliable fix should preserve the printer, protect the computer, and avoid creating a more expensive problem.

### Software source matters

Manufacturer download pages are the best starting point for printer drivers and firmware. Unknown mirrors can carry outdated or modified installation files.

### Physical service cannot be replaced by software

Waste-ink pads, worn rollers, and damaged ports require inspection or replacement when they fail. Software counters do not measure every physical condition.

### Keep firmware procedures uninterrupted

Firmware changes should be made only with the correct model and stable power. Interrupting an update can leave the printer in a recovery state.

### Protect your personal information

Use official contact forms and verified phone details. Never provide bank credentials or one-time passwords to a caller claiming to be a printer technician.

### Test one change at a time

Print a small test page after each meaningful change. This makes it easier to identify which step fixed the problem and prevents unnecessary repeated maintenance.

### Know when to stop troubleshooting

If there is a burning smell, liquid leakage, repeated mechanical grinding, or a persistent service warning, stop using the printer and seek appropriate professional service.
